## Introduction

This project is a SilverStripe vendor module providing various uploader capabilities for silverstripe/cms

1. Uppy upload field for uploads to Silverstripe assets
2. Uppy S3 upload field for direct uploads to an S3 endpoint
3. Abstract uploader field to support other uploaders
4. Upload page for the CMS
5. External upload page for the CMS
6. Editable upload field for Uppy uploads within a form


## Restrictions

1. Do not modify code without approval


## PHP requirements

1. All PHP code should be written to support version 8.3, 8.4 and 8.5

## Frontend build requirements

1. The static CSS and JS to support the Uppy field is managed by Yarn via  a Webpack configuration.
